# TAIYARI

Your Preparation. Your Future.

An exam preparation platform for Indian competitive exams, starting with Railway exams.

## Architecture
Next.js App Router, TypeScript, Tailwind CSS, Supabase PostgreSQL and Auth. AI integrations will be server-side behind a provider interface.

## Development
Phase 1: application shell, exam selection and authentication. Subsequent phases add current affairs, verified PYQs, concept learning, mock tests and revision.

AI-generated practice must be distinguished from verified previous-year questions. News content must retain source attribution and respect licensing.
